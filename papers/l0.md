# L0 Smoothing — L0 梯度最小化图像平滑

> **论文：** Image Smoothing via L0 Gradient Minimization  
> **作者：** Li Xu, Cewu Lu, Yi Xu, Jiaya Jia  
> **发表：** ACM SIGGRAPH Asia 2011, TOG Vol. 30, No. 6  
> **意义：** 首次将 L0 伪范数用于图像平滑，通过半二次分裂 + FFT 实现高效求解

---

## 1. 问题动机

传统 L1/L2 正则化会对所有梯度施加惩罚，导致弱边缘也被模糊。L0 平滑的目标是：**保留少量显著边缘，将其余区域完全平坦化**。

直觉：一幅"干净"的图像应该只有少数像素具有非零梯度（边缘处），其余区域梯度为零（完全平坦）。

---

## 2. 核心能量泛函

$$\min_S \; \underbrace{\sum_p (S_p - I_p)^2}_{\text{数据保真项}} + \lambda \cdot \underbrace{C(S)}_{\text{L0 正则项}} \tag{1}$$

其中 L0 "范数"定义为**梯度非零的像素数**：

$$C(S) = \#\left\{p \;\Big|\; |\partial_x S_p| + |\partial_y S_p| \neq 0\right\} \tag{2}$$

**符号说明：**
- $S$ — 平滑输出图像
- $I$ — 输入图像
- $p$ — 像素索引
- $\lambda$ — 平滑权重（越大，非零梯度越少，图像越平坦）
- $\partial_x S_p = S_{p+1} - S_p$，$\partial_y S_p = S_{p+W} - S_p$ — 水平/垂直前向差分

**为什么难以直接优化？** $C(S)$ 是非凸、非连续的组合优化问题（NP-hard），无法直接用梯度下降。

---

## 3. 半二次分裂（Half-Quadratic Splitting）

### 3.1 引入辅助变量

引入辅助变量 $h_p \approx \partial_x S_p$ 和 $v_p \approx \partial_y S_p$，将原问题松弛为：

$$\min_{S,h,v} \; \sum_p (S_p - I_p)^2 + \lambda \cdot C(h,v) + \beta \sum_p \left[(\partial_x S_p - h_p)^2 + (\partial_y S_p - v_p)^2\right] \tag{3}$$

其中：
- $C(h,v) = \#\{p \mid |h_p| + |v_p| \neq 0\}$
- $\beta > 0$ 是惩罚参数，控制 $(h,v)$ 与 $(\partial_x S, \partial_y S)$ 的接近程度
- 当 $\beta \to \infty$ 时，约束 $h = \partial_x S$, $v = \partial_y S$ 严格成立，式 (3) 收敛到式 (1)

### 3.2 交替最小化策略

固定一组变量，对另一组求最优解，交替迭代：

$$\text{Step A: 固定 } S \text{，对 } (h,v) \text{ 求最优}$$
$$\text{Step B: 固定 } (h,v) \text{，对 } S \text{ 求最优}$$

---

## 4. 子问题 A：求解 $(h, v)$（逐像素阈值）

固定 $S$，式 (3) 对每个像素 $p$ 独立分解：

$$\min_{h_p, v_p} \; \underbrace{(h_p - \partial_x S_p)^2 + (v_p - \partial_y S_p)^2}_{\text{二次惩罚}} + \frac{\lambda}{\beta} \underbrace{H(|h_p| + |v_p|)}_{\text{L0 项}} \tag{4}$$

其中 $H(x) = \mathbf{1}[x \neq 0]$（Heaviside 函数）。

### 4.1 分情况讨论

**情况 1：令 $(h_p, v_p) = (0, 0)$**

代价 $= (\partial_x S_p)^2 + (\partial_y S_p)^2 + 0$

**情况 2：令 $(h_p, v_p) = (\partial_x S_p, \partial_y S_p)$（非零）**

代价 $= 0 + \frac{\lambda}{\beta}$

选择代价更小的方案：

$$\boxed{(h_p, v_p) = \begin{cases} (0, 0) & \text{若 } (\partial_x S_p)^2 + (\partial_y S_p)^2 \leq \dfrac{\lambda}{\beta} \\[6pt] (\partial_x S_p, \partial_y S_p) & \text{否则} \end{cases}} \tag{5}$$

**直觉：** 当梯度幅值的平方小于阈值 $\lambda/\beta$ 时，将其"截断"为零（消除弱纹理）；否则保留（保持强边缘）。这是一个**硬阈值**操作。

---

## 5. 子问题 B：求解 $S$（FFT 闭式解）

固定 $(h, v)$，对 $S$ 最小化：

$$\min_S \; \sum_p (S_p - I_p)^2 + \beta \sum_p \left[(\partial_x S_p - h_p)^2 + (\partial_y S_p - v_p)^2\right] \tag{6}$$

### 5.1 矩阵形式

写成矩阵形式（$S, I, h, v$ 均为 $N$-维向量）：

$$\min_S \; \|S - I\|^2 + \beta \left[\|D_x S - h\|^2 + \|D_y S - v\|^2\right]$$

对 $S$ 求梯度并令其为零：

$$2(S - I) + 2\beta D_x^T(D_x S - h) + 2\beta D_y^T(D_y S - v) = 0$$

$$\left(I + \beta D_x^T D_x + \beta D_y^T D_y\right) S = I + \beta D_x^T h + \beta D_y^T v \tag{7}$$

### 5.2 FFT 对角化

在**周期边界条件**下，差分算子 $D_x, D_y$ 是循环矩阵，可被 DFT 对角化：

$$D_x \leftrightarrow \mathcal{F}(d_x), \quad d_x = [\ldots, 0, -1, 1, 0, \ldots]$$

利用卷积定理，式 (7) 在频域变为逐元素除法：

$$\mathcal{F}(S) = \frac{\mathcal{F}(I) + \beta\left(\overline{\mathcal{F}(d_x)} \odot \mathcal{F}(h) + \overline{\mathcal{F}(d_y)} \odot \mathcal{F}(v)\right)}{\mathcal{F}(\mathbf{1}) + \beta\left(|\mathcal{F}(d_x)|^2 + |\mathcal{F}(d_y)|^2\right)} \tag{8}$$

$$\boxed{S = \mathcal{F}^{-1}\!\left(\frac{\mathcal{F}(I) + \beta\left(\overline{\mathcal{F}(d_x)} \odot \mathcal{F}(h) + \overline{\mathcal{F}(d_y)} \odot \mathcal{F}(v)\right)}{1 + \beta\left(|\mathcal{F}(d_x)|^2 + |\mathcal{F}(d_y)|^2\right)}\right)} \tag{9}$$

**注意：** 分母 $1 + \beta(|\mathcal{F}(d_x)|^2 + |\mathcal{F}(d_y)|^2)$ 与 $\beta$ 有关，但 $|\mathcal{F}(d_x)|^2 + |\mathcal{F}(d_y)|^2$ 可以**预计算**，每次迭代只需更新 $\beta$。

### 5.3 分母的显式形式

对于标准前向差分 $d_x = [-1, 1, 0, \ldots, 0]$（循环），其 DFT 为：

$$\mathcal{F}(d_x)[k] = e^{i2\pi k/N} - 1$$

$$|\mathcal{F}(d_x)[k]|^2 = 2 - 2\cos(2\pi k/N) = 4\sin^2(\pi k/N)$$

类似地，$|\mathcal{F}(d_y)[l]|^2 = 4\sin^2(\pi l/M)$（$M$ 为图像高度）。

---

## 6. 完整算法

```
输入：图像 I，参数 λ，β₀ = 2λ，βmax = 1e5，κ = 2
初始化：S ← I，β ← β₀

预计算：
  F_dx = FFT(d_x)，F_dy = FFT(d_y)
  denom_base = |F_dx|² + |F_dy|²   // 与 β 无关的部分
  F_I = FFT(I)

while β < βmax:
  // Step A：逐像素硬阈值（式 5）
  grad_x = diff_x(S)，grad_y = diff_y(S)
  mask = grad_x² + grad_y² > λ/β
  h = grad_x · mask
  v = grad_y · mask

  // Step B：FFT 求解（式 9）
  numerator = F_I + β·(conj(F_dx)·FFT(h) + conj(F_dy)·FFT(v))
  denominator = 1 + β·denom_base
  S = IFFT(numerator / denominator).real

  β ← κ·β

输出：S
```

**迭代次数：** 约 20~30 次（$\beta$ 从 $2\lambda$ 增长到 $10^5$，每次乘以 $\kappa=2$，约 $\log_2(10^5/2\lambda)$ 次）。

---

## 7. 收敛性分析

随着 $\beta \to \infty$：
- 惩罚项 $\beta\|D_x S - h\|^2$ 强制 $h \to \partial_x S$
- 此时式 (3) 趋近于原始 L0 问题式 (1)
- 实践中 $\beta_{\max} = 10^5$ 已足够收敛

**注意：** 由于 L0 问题本身非凸，算法收敛到局部最优，但实验表明结果质量良好。

## 8. 参数效果

| $\lambda$ | 效果 |
|-----------|------|
| $0.01$ | 轻微平滑，保留大部分细节 |
| $0.02$ | 中等平滑，去除弱纹理 |

## 9. 与其他方法的比较

| 方法 | 正则项 | 求解方式 | 边缘保持 |
|------|--------|---------|---------|
| 高斯滤波 | $\ell_2$ 梯度 | 卷积 | 差 |
| 双边滤波 | 加权 $\ell_2$ | 迭代 | 中 |
| WLS | 加权 $\ell_2$ | 线性系统 | 好 |
| **L0 Smoothing** | **L0 梯度计数** | **半二次分裂 + FFT** | **极好（完全平坦化）** |
| RTV | 相对全变分 | IRLS + 线性系统 | 好（结构/纹理分离） |
